BeautyWomenBeautyWomen es una plataforma web integral diseñada para la gestión, promoción y comercialización de productos de belleza y cuidado personal.

El proyecto está enfocado en ofrecer una experiencia de usuario visualmente atractiva, intuitiva y fluida, permitiendo a los clientes explorar un catálogo dinámico de cosméticos mientras proporciona a los administradores herramientas eficientes para el control de inventario y ventas.

🎯 Objetivos del ProyectoOptimizar la experiencia de compra: Permitir que los usuarios encuentren y filtren productos de belleza según su tipo de piel, marca o categoría de manera sencilla.Centralizar la información: 

Gestionar de forma segura los datos de usuarios, productos, stock y pedidos en un único sistema de almacenamiento.

Diseño Responsivo: Garantizar que la interfaz se adapte perfectamente a dispositivos móviles, tabletas y computadoras de escritorio.

🛠️ Arquitectura TecnológicaEl proyecto se desarrolla utilizando un enfoque clásico y robusto de desarrollo web:

Frontend (Interfaz de Usuario):HTML5: Utilizado para estructurar de manera semántica el contenido del sitio (formularios de registro, catálogo de productos, carrito de compras y pasarela de pago simulada).

CSS3: Encargado del diseño visual, tipografías, transiciones y una paleta de colores sofisticada (tonos pasteles, nude y dorados) alineada con la estética de la industria de la belleza. 

Incluye diseño adaptable mediante Flexbox o CSS Grid.

Base de Datos:SQL (ej. MySQL o PostgreSQL): Estructura el modelo de datos relacional. 

Se encarga de almacenar la información crítica del negocio mediante tablas interconectadas para clientes, productos, categorías, carritos y transacciones.

📋 Módulos Principales del SistemaCatálogo Virtual Interactivo: Vista de productos con imágenes de alta calidad, descripciones detalladas, precios y filtros avanzados (por ejemplo: maquillaje, cuidado facial, capilar).

Gestión de Usuarios: 

Registro e inicio de sesión seguro para clientes y administradores.
